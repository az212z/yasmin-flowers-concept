# ورود الياسمين — نموذج موقع مقترح

موقع عربي RTL متعدد الصفحات لعرض فكرة تصميم على محل ورود الياسمين بالرياض. **غير رسمي وغير معتمد من المحل، ولا يستقبل طلبات فعلية.**

## التشغيل
من مجلد المشروع:
```sh
python3 -m http.server 4173
```
افتح http://localhost:4173 . لا توجد حزمة build أو تبعيات تثبيت.

اختبارات منطق تخصيص الباقة (Node.js 20 أو أحدث):
```sh
node --test tests/bouquet.test.mjs
```

## الصفحات
- index.html: الرئيسية.
- collection.html: كتالوج توضيحي مع تصنيف وتفاصيل.
- custom.html: تخصيص باقة ومعاينة ونسخ الملخص.
- visit.html: العنوان والاتصال والخرائط.
- faq.html / privacy.html: الأسئلة والخصوصية.
- 404.html: الصفحة البديلة.

## تعديل المحتوى
- التنسيقات: assets/catalog.mjs. غيّر العنوان والوصف والمسار والنص البديل والمناسبة.
- الصور: assets/images/ مع الحفاظ على أسماء الملفات أو تعديل مراجعها.
- الهوية والألوان والمقاسات: assets/styles.css.
- التحقق والملخص: assets/bouquet.mjs؛ الواجهة assets/custom.js.
- بيانات الاتصال: visit.html؛ الاسم والتذييل موجودان في الصفحات كلها.

## النشر
GitHub Pages من فرع main ومسار الجذر /. الروابط نسبية وتعمل داخل مسار المستودع. ملف .nojekyll موجود. لا توجد مفاتيح API أو خدمات خلفية.

## التسليم
راجع docs/SALES-PACK.md للعرض التجاري، docs/SOURCES.md للمصادر والتراخيص، وdocs/QA.md لنتائج الفحص. قبل التشغيل الرسمي يلزم اعتماد المالك للمحتوى والصور والأسعار والهوية ووسائل الطلب. الدفع وإدارة المخزون ولوحة التحكم وخدمة التوصيل خارج نطاق النموذج.

المحتوى الموجود في نموذج الباقة مؤقت في ذاكرة الصفحة فقط. الصور والخطوط محلية ولا يضاف أي متتبع. جميع الصفحات تحمل noindex,nofollow؛ ذلك توجيه للفهرسة وليس حماية وصول.
