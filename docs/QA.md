# التحقق من الموقع

التاريخ: 13 نوفمبر 2026.

- خمسة اختبارات Node نجحت: المدخلات، الحدود، الميزانية، النص الشبيه بـHTML، وتغير الملخص ونجاح/فشل الحافظة.
- تم فحص الرئيسية والكتالوج والمخصص والزيارة والأسئلة والخصوصية بعروض 390 و768 و1440؛ عرض المستند يساوي عرض الشاشة في الحالات الـ18.
- تمت مراجعة التصميم بصريًا على الكمبيوتر والجوال/اللوحي، وفتحت الصفحات مباشرة تحت مسار المشروع.
- فلتر الشكر يعرض تنسيقين؛ نافذة التفاصيل تفتح وتغلق عبر Escape وتعيد التركيز لزر الفتح.
- نموذج فارغ يعرض خطأ؛ اختيار مناسبة ولون وتحرير رسالة يحدّث الملخص. النسخ نجح في المتصفح. النص الشبيه بـHTML بقي نصًا ولم يُنشئ عناصر.
- فشل الحافظة اختُبر في الوحدة بحقن كاتب يرفض؛ لم تُغيّر صلاحيات المتصفح لفرض الرفض في الواجهة.
- قائمة الجوال فتحت، ولا توجد أخطاء console في جولة الصفحات.
- جميع الصور المحلية موجودة؛ عنصر الصورة في dialog مخفي بلا src إلى أن يختار المستخدم تنسيقًا.
- الصور الست مجتمعة أقل من 800KB، والخطوط محلية.
- مراجعة مستقلة اكتشفت وأصلحت: مسارات 404 المتداخلة، وزر إرسال النموذج عند غياب JS. زر submit معطل في HTML ويُفعّل بعد تسجيل المعالج. القائمة لها بديل noscript.
- روابط الهاتف والخرائط فُحصت دون الاتصال أو إرسال رسالة. لا توجد مدفوعات أو تحليل أو تخزين مدخلات دائم.

## النشر العام

نجح بناء GitHub Pages للنسخة 24372a3، وأعاد الرابط العام HTTP 200. فُتحت الرئيسية في المتصفح وتأكد تحميل الخط والصور، وفُتحت custom.html مباشرة وعمل ملخص الباقة. فُحص مسار مفقود متداخل وعرض صفحة 404 المخصصة؛ زر العودة أوصل إلى الرئيسية بنجاح.
